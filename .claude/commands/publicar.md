Prepare a publicação do app:

1. Rode `npm run build` e `npm test`. Se falhar, pare e conserte antes de seguir.
2. Mostre `dist/hashes.txt`.
3. Se o projeto já estiver ligado à Vercel por Git, basta fazer commit e push (a Vercel monta sozinha). Faça o commit apenas se eu pedir.
4. Lembre-me de conferir, no iPhone, se o app carregou a versão nova (fechar e abrir o ícone uma ou duas vezes).
